Bossanova808 Private
===================================

`script.bossanova808.private`

**Testing only - this add-on may break your system - DON'T INSTALL!**

A private marker add-on for Bossanova808's own Kodi systems. When it is installed and enabled, the Bossanova808 Confluence skins (Omega and Piers) switch on household-specific behaviour, such as custom TV menus for the Adults profiles, fast Adults/Kids profile switching, family birthday backgrounds, and skin utilities.

The skins check for it with `System.AddonIsEnabled(script.bossanova808.private)`, exposed as `$EXP[IsBossanova808]`. Because add-ons are installed per Kodi install rather than per profile, one install covers every profile on a box. Disabling or uninstalling it returns the skins to their standard behaviour.

If you have installed this by accident, please uninstall it.
