v2.1.0 (2026-10-29)
- Add "Limp: toggle video as software decode" (replacing the one-off "Limp: software decode") - it remembers a video so it always uses software decoding until toggled off again, and the new By Video settings page lists them
- The two series context menu items are now a single "Limp: toggle series as software decode", and the By TV Show settings page is now By Series
- Notifications now use the Limp icon
- Limp no longer checks what is focused every second when no rules, series or videos are set up

v2.0.0 (2026-10-26)
- Limp is now more general: choose when it uses software decoding - for videos Amlogic's hardware decoder gets wrong, or for all videos 1080p and below
- The rules now apply everywhere by default (the Apply everywhere option is gone) - limit them to paths on the new Path Limits page, with a Clear all paths button
- Settings are now General, By TV Show and Path Limits pages
- Add Windows support, and untested support for Apple devices and webOS
- Add an option, on by default, to force hardware decoding on at start-up in case it has been left off
- If Limp finds hardware decoding switched off mid-session when it is not the one holding it off, it asks if you want to turn it back on

v1.2.0 (2026-10-20)
- Add "Limp: software decode series" and "Limp: stop software decoding series" context menu items, to always use software decoding for a TV series (e.g. 50 fps shows that drop frames) - manage the list in settings
- Add start-up and periodic checks that hardware decoding is restored, e.g. after a Kodi crash or profile switch
- Split the settings into General and By Path pages

v1.1.0 (2026-10-05)
- Add a "Limp: software decode" context menu item to play any video with software decoding, e.g. files outside your Limp paths (can be turned off in settings)

v1.0.0 (2026-08-26)
- Detects and forces software decoding for video that trips up Amlogic's amcodec hardware decoder - files with a rotation tag, and MJPEG-in-AVI clips that hang on hardware decode entirely
- Scope it to specific paths, or apply everywhere
- Restores hardware decoding once affected playback ends
